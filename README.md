# tvtracker-mcp

MCP-сервер для сериалов: находит сериал **по описанию**, ведёт прогресс просмотра и
считает, что у тебя накопилось. Это не обёртка над API — три ключевых ответа
(поиск по тексту описаний, бэклог, рейтинговый профиль по сезонам) считает наш код,
потому что ни TVmaze, ни локальная база поодиночке их не дают.

## Статус

Работает: 5 инструментов, 5 ресурсов, 4 промпта, корпус на 89 664 сериала.
Архитектура — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), план реализации —
[`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md), дизайн примитивов —
[`docs/DESIGN.md`](docs/DESIGN.md), замеры — [`docs/EVALS.md`](docs/EVALS.md).

| Примитив | Что делает |
| --- | --- |
| `show_search` | поиск по названию, **по описанию сюжета** и фильтрация каталога |
| `show_profile` | факты + рейтинги по сезонам + твоя позиция, один вызов вместо четырёх |
| `episode_search` | поиск серии по описанию, с защитой от спойлеров |
| `tracking_update` | все изменения состояния одним инструментом с enum-действием |
| `watch_next` | решение «что включить» за один вызов |
| `tracking://watching` `backlog` `schedule` `taste` | личный контекст, подаётся хостом |
| `catalog://facets` | допустимые значения фильтров с точным написанием |
| `whats_next` `catch_up` `find_by_vibe` `season_verdict` | четыре промпта-рамки |

## Быстрый старт

```bash
uv sync --all-groups          # окружение
cp .env.example .env          # конфиг (секретов нет: TVmaze без ключа)
uv run tvtracker sync --full  # ~380 запросов, ~4 минуты, корпус в SQLite
uv run mcp dev src/tvtracker/server.py   # MCP Inspector
```

Подключение к Claude Code — `uv run mcp install src/tvtracker/server.py`.

## Оценка качества

## Атрибуция

Данные о сериалах предоставлены [TVmaze](https://www.tvmaze.com/) и распространяются по
лицензии [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/). Этот проект использует
их на тех же условиях и ссылается на TVmaze как на источник.
API: <https://www.tvmaze.com/api>.

## Ограничение, о котором нужно знать

Описания сериалов и серий на TVmaze пишут пользователи. Такой текст попадает в контекст
модели, то есть является потенциальным вектором непрямой инъекции промпта. Мы чистим HTML,
жёстко режем длину и помечаем пользовательский текст маркером источника — но полностью
проблема не решается. Не давайте серверу инструментов с побочными эффектами вне трекинга.
